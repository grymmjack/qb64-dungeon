# ============================================================================
#  SECTORS -- the 9 dungeon levels as coloured rectangles on the board.
#
#  Each sector is a rectangle (in CELLS, 1-based col/row) with a COLOUR that must
#  match the room-block colour the board art uses for that level -- collision and
#  "which level am I on" both resolve by testing position against these rects and
#  matching this colour (SECTOR.get_by_xy / in_room). Change the art's level colour
#  and you MUST change it here too, or movement silently breaks.
#
#  Format:  id | label | col1 | row1 | col2 | row2 | RRGGBB
#  ( id 1-9; RRGGBB = 6 hex digits, '#' optional; fields are trimmed; '#' line = comment )
# ============================================================================
