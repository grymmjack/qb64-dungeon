# ============================================================================
#  SECTORS -- the 9 dungeon levels: id, label and COLOUR.
#
#  GEOMETRY IS NOT AUTHORED HERE. DeriveSectors (game/SECTOR.bas) computes each
#  level's rectangle from the BOARD ART at load: the tight bounding box of every
#  cell painted uniformly in that level's colour, then expanded until it meets a
#  neighbour or the board edge (which is what claims the corridors between rooms).
#
#  The col/row columns below are IGNORED. They are kept so existing data packs
#  still parse; only id, label and RRGGBB are read. The colour is the important
#  one -- it is how a painted cell announces which level it belongs to, and it
#  must match the board art EXACTLY (an off-by-one channel makes the level vanish).
#
#  Two files used to say where a level is -- these rects and a hand-painted
#  board-132x50-sector-mask.ans -- and the art said it a third time. When the
#  copies disagreed with the art, 12 rooms the art painted at level 5/6 sat under
#  a mask claiming level 1 and simply never existed. Now there is one source.
#
#  id | label | col1 | row1 | col2 | row2 | RRGGBB      (col/row ignored)
