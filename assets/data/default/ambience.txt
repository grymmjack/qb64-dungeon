# ============================================================================
#  AMBIENCE -- the dungeon making noise at you while you walk.
#
#  A random line fires every AMB_SECS_MIN..AMB_SECS_MAX seconds of PLAY (never
#  during combat, menus or banners -- AmbienceTick only runs in the play loop).
#  Set AMB_SECS_MIN to 0 in tuning.txt to turn ambience off entirely.
#
#  Format:  level | sfx name | weight
#     level   1-9, or 0 = "any level" (these are always in the pool)
#     sfx     an effect name; it resolves through the SFX PACK like any other,
#             so a pack can re-voice the whole dungeon. A name with NO file is
#             simply SILENT -- ambience never falls back to the tone beeper,
#             because a PC-speaker blip is a UI sound, not a distant noise.
#     weight  relative odds within that level's pool (1 = rare, 5 = often)
#
#  Levels have a character: the Torture Chamber screams, the Crypt moans, the
#  Wizard's floor mutters to itself. Keep the pools small and thematic -- the
#  point is punctuation, not a soundscape.
# ============================================================================
