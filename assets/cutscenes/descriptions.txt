# descriptions.txt -- generation prompts for CUT-SCENE art.
#
# Format:  path | size | prompt        (path is relative to assets/cutscenes/<pack>/art/)
#
# `dungeon.run imagemanifest audit` scans every .cut in every pack, and any art that
# resolves NOWHERE is listed as a gap with the prompt from this file. Art a scene names
# that the game already ships (classes/wizard.png, monsters/...) is NOT listed here --
# imagemanifest already owns those trees.
#
# BACKDROPS ARE 264x204 and are sized in the scene with `fill`, never a `scale` number:
# a scale factor is correct for exactly one source size, so regenerating art a little
# smaller silently letterboxes every scene that used it -- which looks identical to a
# missing backdrop. 264x204 is a clean quarter of the 1056x816 screen, so it also scales
# by whole pixels.
#
# Generate flat (pixelmon --snap-pixels --smooth mode); the raw downscale is noisy, and
# at 4-8x magnification that noise becomes blocks of confetti.
