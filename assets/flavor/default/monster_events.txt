# monster_events.txt -- what each MONSTER does in combat, so its text fits its biology
# (a slime dissolves, a dragon breathes fire -- neither one "claws").
# Format:  MONSTER | event | text | narrkey     (fields trimmed; '#' = comment; blanks skipped)
#
#   narrkey  OPTIONAL 4th column -- the narration key this line is spoken under.
#            Most rows stop at three and are shown but never voiced. It was left
#            out of this comment for a long time while LoadEventText read it, and
#            the data editor believed the comment: editing the text column would
#            have swallowed the key into the line the player reads.
#            `dungeon.run schemalint` compares this comment against the declared
#            schema in game/DATATABLES.bas precisely so that cannot recur.
# events:  attack (it hits you)   miss (it misses)   crit (a devastating hit)
#          fumble (it botches its attack)   death (it is slain)
# key "*" = the default for any monster with no line of its own for that event, so you
# only need specific lines where they matter. Up to a handful per (monster,event);
# one is picked at random. Re-read at F5.
#
# Tokens: {player} {class} {mon} {dmg} {deaths} {level} {room} {treasure} {weapon}
# Grammar tokens (agree with singular vs PLURAL monsters like GIANT RATS / GHOULS):
#   verb{s} verb{es}  ->  drop the ending in the plural (strike{s} = strikes / strike)
#   {is}=is/are  {was}=was/were  {has}=has/have  {it}=it/they  {its}=its/their
#
# NARRATION KEY (optional 4th field). A line with a key can be SPOKEN: the audio file is
# assets/narration/<pack>/<key>.<ext>, and `dungeon.run audiomanifest` lists it for the
# generator. A line with NO key is shown but never spoken.
#
# Only TOKEN-FREE lines get a key. A line containing {mon} / {dmg} / {weapon} reads
# differently every fight, so no single recording can ever match it -- pre-recording
# "You strike the {mon} for {dmg} damage" would literally say "the mon". Keep that rule if
# you add lines: put the token version and a spoken version in as SEPARATE rows.
# --------------------------------------------------------------------------------------

# ================= generic fallback for ANY monster =================
# Grammar tokens keep these correct for singular AND plural monsters (GIANT RATS,
# GHOULS...):  verb{s}/{es} drop their ending in the plural, {is}/{its}/{it} agree too.
* | attack | The {mon} strike{s} you for {dmg} damage.
* | attack | The {mon} press{es} {its} attack and land{s} a blow for {dmg}.
* | miss | The {mon} lunge{s}, but you weather the assault.
* | miss | The {mon} strike{s} wide -- you dance out of reach.
* | miss | You duck the blow aimed at your head. | combat.mon.miss.duck-blow-aimed
* | miss | You twist aside as the {mon} lunge{s} past.
* | miss | The {mon} snap{s} at the empty air where you stood.
* | miss | You throw yourself clear of the {mon}.
* | miss | The {mon} overreach{es}; you slip beneath {its} guard.
* | miss | You parry the attack at the last instant. | combat.mon.miss.parry-attack-last
* | miss | The {mon} misjudge{s} the distance and find{s} only air.
* | miss | You sidestep, and the attack whistles harmlessly past. | combat.mon.miss.sidestep-attack-whistles
* | miss | The {mon} lash{es} out -- but you are already gone.
* | crit | The {mon} catch{es} you flush -- a savage blow for {dmg}!
* | fumble | The {mon} lash{es} out wildly and {its} attack finds only stone.
* | fumble | The {mon} misjudge{s} the strike -- the blow goes wide and wasted.
* | death | The {mon} shudder{s} and collapse{s}, slain.
* | death | The {mon} fall{s} still at last.
